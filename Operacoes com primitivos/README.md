## DETALHAMENTO

Foram feitos os mesmos códigos em 3 linguagens diferentes: Python, Java e Javascript. Principal intuito é analisar como funciona a sintaxe e os tipos primitivos em diferentes linguagens.

Foi utilizado principalmente o Visual Studio Code e o Intelijj para o Java em específico. Todos criados e atualizados localmente pelo computador e atualizados para o diretório remoto a partir do Git bash.
